### T1. Extract the neutral turn state machine from cox-core

aulo task T1.15 (decision T0.7). Ported from cox's `cox-core` (cox is untouched): the step loop of `session.rs` (`run_turn`, `step`, `finish`), the stream consumer `consume_provider` and the tool batch of `turn.rs` (`run_signed_tools`, `gate`, `ask`, `results_message`), with the neutral subset of cox-protocol's `Submission`, `Event`, `ItemKind`, `ToolCall`, `Segments`, `ToolResult`, `Diff`, `Decision`, `DecidedBy`, `Why` and `CoreError` (as `LoopError`) under the same serde tags. The domain work moved behind trait seams: `Tools`, `Approvals`, `Context`, `EventSink`, plus `llm_wire::Provider`. Stayed in cox: routing, budget, compaction, repo map, prompts, memory, checkpoints, rewind, subagents, hooks, sandbox, archive, dedup, telemetry. Deliberate differences: an interrupt mid-stream ends the turn `Interrupted` at once; no call starts after an interrupt; an interrupted tool round keeps its results in history; new `approval_timeout` and `tool_output_cap`. Tests port cox-core's loop tests (event order of text-only, one-tool, max-steps, provider-error and interrupt turns; parallel result order; allow, deny, allow-for-session, edit) and add scripted-provider tests for an interrupt mid-stream against a provider that ignores cancel, an interrupt during an approval, rule denies, the approval timeout, parallel cap and exclusive ordering, streamed output and the output cap.
