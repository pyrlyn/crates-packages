# llm-catalog — completed tasks

### T1.5. Extract llm-catalog: model catalog and prices

Copied from cox's `cox-models` so aulo can share one catalog; cox is untouched. Moved: `Catalog` (built-in, plugin fill-only, configured and user-price layers, `overlay_served`, `supports_adaptive_thinking`), `ModelRow`, `Capabilities`, `RowSource`, `PriceTable` and `Price`, and `effort_for` with `Api` and `WireEffort`; the embedded `prices.toml`; with their unit tests. Differences from cox: the built-in rows are a `models.toml` copied from `default.toml`'s `[providers.*].models` (cox's `default.toml` is a whole config and stays in cox); `Catalog::load` takes `&[ModelEntry]` instead of cox's `Config`, and plugin rows are `PluginModel`/`PluginPrice` instead of the manifest's `ModelDecl`/`PriceDecl` (no `provider` field, which the catalog never read); `ModelId`, `Usage` and `Effort` come from `llm-wire`; `CatalogError::Config` is `CatalogError::Models`; new JSON Schemas for `models.toml` and `prices.toml` with a stale-schema test; the cox test that every configured model is priced became "every built-in model is priced" (the tier and provider defaults stay with cox's config). Check: `cargo test -p llm-catalog` (24 tests), `cargo clippy -p llm-catalog --all-targets -- -D warnings` and `cargo fmt --all --check` green.
